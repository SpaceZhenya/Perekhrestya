# Перехрестя (Perekhrestya)

🎮 3D-adventure / psychological drama у браузері.

Хата, яка пам'ятає. Ти повертаєшся в покинуте село після смерті бабусі. Але хата більша всередині, ніж зовні. Кожна кімната — інший час. Кожен предмет — спогад.

## Як грати

1. Відкрий `index.html` у браузері (Chrome/Edge)
2. Натисни на екран — увійдеш
3. **WASD** — ходити, **Миша** — озиратися, **E** — взаємодіяти
4. Знайди ключ біля печі → відчини двері в підвал

## Прототип v0.1

- 3D-хата з кухнею, піччю, столом
- Інтерактивні предмети зі спогадами
- Загадка з ключем
- Атмосфера: дощ, сутінки, мерехтіння печі
- Фінал з переходом у підвал

## Стек

- Three.js (WebGL)
- Чистий HTML/CSS/JS — без встановлення
